## 3. 회원 권한 부여(REQ-ADMIN-004) 설계 규칙

지금은 구현하지 않지만 나중에 다시 설계하지 않도록 API 명세 10장에 아래 규칙을 넣었습니다.

| 규칙 | 내용 |
| --- | --- |
| 권한 필드 | `users.role` 문자열 enum. 현재 `USER` / `ADMIN`, 추후 `MODERATOR` 등 추가. `is_admin` 같은 boolean 금지 |
| 권한 검사 | `role === 'ADMIN'` 직접 비교 대신 역할별 권한 매핑 표 한 곳을 거침 (예: `can(user, 'content.hide')`) |
| 부여 단위 | 회원별이 아니라 역할별 |
| 추후 결정 (D-15) | 중간 권한의 조치 범위, 관리자 글 조치 가능 여부, 권한 변경 API, 활동 로그 `CHANGE_ROLE`, 권한별 관리자 메뉴 노출 |
